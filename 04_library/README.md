# 04 図書館のコードをリファクタリングする

本の貸し出しと返却を管理する、小さな図書館のプログラムです。現在の動作は完成していますが、会員や本を探す処理が重複しています。動作を変えずにコードを整理します。

**リファクタリング**は、外から見た動作を維持しながら、内部の構造を改善することです。この課題では、新機能を追加せず、複数ファイルにまたがる検索処理を共通化します。

## ファイルと読む順序

| 順序 | ファイル | 役割 |
| --- | --- | --- |
| 1 | `main.py` | 本・会員の準備、貸し出し、表示、返却 |
| 2 | `book.py`、`member.py` | 本と会員の情報 |
| 3 | `library.py` | 本と会員の管理、貸し出しと返却 |
| 4 | `report.py` | 一覧を表示する文字列の作成 |
| 5 | `tests/test_library.py` | 状態の変更と不正な操作の確認 |
| 6 | `tests/test_report.py` | レポートの内容と、表示による状態の不変を確認 |

## 現在のクラスと動作

| 対象 | 属性・メソッド | 役割 |
| --- | --- | --- |
| `Book` | `book_id: int`、`title: str`、`borrower_id: int \| None` | 借りている会員のID。貸出可能なら `None` |
| `Member` | `member_id: int`、`name: str` | 会員の情報 |
| `Library` | `books: list[Book]`、`members: list[Member]` | 本と会員の一覧 |
| `lend_book(book_id, member_id) -> None` | 貸し出し | 対象Bookの `borrower_id` を会員IDに変更する |
| `return_book(book_id, member_id) -> None` | 返却 | 借りた本人による返却なら `borrower_id` を `None` にする |
| `build_report(library) -> str` | 一覧 | 本の順序を保って文字列を返す。オブジェクトを変更しない |

## 維持する仕様

| 条件 | 発生させる例外 |
| --- | --- |
| 会員IDが存在しない | `ValueError("会員が見つかりません")` |
| 会員は存在するが、本のIDが存在しない | `ValueError("本が見つかりません")` |
| 貸出中の本をもう一度貸し出す | `ValueError("貸出中です")` |
| 貸し出されていない本を返却する | `ValueError("この本は貸し出されていません")` |
| 別の会員が返却する | `ValueError("借りた会員と一致しません")` |

- 貸し出し・返却では、会員の存在を先に、本の存在を次に確認します。両方不明な場合は会員のエラーを優先します。
- 不正な操作では、貸出状態を変更しません。
- 元のBookオブジェクトの状態を更新します。別のBookを作って置き換えません。
- レポートは、貸出可能な本と貸出中の本を区別し、借りた会員名を表示します。
- 空の図書館のレポートは `図書館の本:` の1行です。末尾の改行は付けません。
- 本が参照する会員が見つからない場合、レポートも `ValueError("会員が見つかりません")` にします。
- IDは重複しない整数とし、元データや出力文言は変更しません。

## 整理する内容

- `Library` に `find_book(book_id: int) -> Book` と `find_member(member_id: int) -> Member` を追加します。
- それぞれ、対象のオブジェクトを返し、見つからない場合は表にある例外を発生させます。
- 貸し出し・返却にある重複した検索を、このメソッドを使う形へ変更します。
- `report.py` にある会員検索も、同じ共通処理を使う形へ変更します。
- `lend_book`、`return_book`、`build_report` の名前、引数、動作を維持します。
- 検索処理以外の仕様変更、JSON対応、メニュー追加は行いません。

## 準備と実行

このフォルダーを作業ディレクトリにして実行します。

```bash
python -m pip install -r requirements.txt
python main.py
python -m pytest -q
```

配布時のテストは **4件成功** します。変更前の出力は、変更後も同じである必要があります。

```text
図書館の本:
1: Python入門 [貸出中: 田中]
2: データの扱い方 [貸出可能]

返却後:
図書館の本:
1: Python入門 [貸出可能]
2: データの扱い方 [貸出可能]
```

## 確認するケース

既存テストに加え、不明な会員ID、本のID、未貸出の本の返却、両方不明なときのエラーの優先順、空のレポート、返却後のレポートを確認するテストを追加します。現在のコードでも成功することを確認してから、リファクタリングに進みます。

新しい検索メソッドが元のオブジェクトを返すこともテストします。変更後も全テストが成功し、出力と例外の内容が維持されることを確認してください。

## 提出

主な変更対象は `library.py`、`report.py` とテストです。提出する `work_notes.md` には、整理した処理、変更前後で同じことを確認した動作、実行結果を記録してください。
