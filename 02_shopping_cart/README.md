# 02 買い物かごの計算を修正する

JSONのカタログから商品を読み込み、商品と数量を買い物かごに追加して合計金額を求めるプロジェクトです。複数のファイルを調べ、計算の不具合を修正し、不正な数量を防ぎます。

## 配布時の状態

プログラムは動きますが、数量が計算に反映されません。`python main.py` の最初の出力は次のとおりです。

```text
りんご × 2: 200円
牛乳 × 3: 250円
合計: 450円
```

初期テストは **2件成功、1件失敗** します。`test_total_uses_quantities` の失敗は、この不具合を再現するためのものです。期待値を変更せず、原因を修正してください。

## ファイルと読む順序

| 順序 | ファイル | 役割 |
| --- | --- | --- |
| 1 | `main.py` | 商品を読み、カートに追加して結果を表示 |
| 2 | `product.py` | 商品のID・名前・価格 |
| 3 | `catalog.py`、`products.json` | 10商品の読み込みと元データ |
| 4 | `cart_item.py` | 商品一つと数量、小計 |
| 5 | `cart.py` | 明細一覧、追加、合計 |
| 6 | `tests/test_cart.py` | 現在の動作を確かめる初期テスト |

## クラスと仕様

| 対象 | 属性・メソッド | 完成後の動作 |
| --- | --- | --- |
| `Product` | `product_id`、`name`、`price` | 商品の情報。価格は円単位の整数 |
| `CartItem` | `product`、`quantity` | 商品オブジェクトと購入数量 |
| `CartItem.subtotal() -> int` | 小計 | 価格と数量から小計を求める |
| `Cart` | `items: list[CartItem]` | カートの明細一覧 |
| `Cart.add_item(product, quantity) -> None` | 追加 | 条件を確認して明細を1件追加する |
| `Cart.total() -> int` | 合計 | 全明細の小計を合計する。空なら `0` |

数量は **1以上の整数** とします。`0`、負の数、`1.5`、`"2"`、`None`、`True`、`False` は認めません。不正な数量では `ValueError("数量は1以上の整数にしてください")` を発生させ、カートの内容は変更しません。

同じ商品を2回追加した場合は、別々の明細として保持します。両方の明細を合計してください。商品の価格は変更しません。商品カタログの内容は正しいものとして扱い、価格の検証や割引機能は追加しません。

修正後の `main.py` の出力:

```text
りんご × 2: 400円
牛乳 × 3: 750円
合計: 1150円
```

## 準備と実行

このフォルダーを作業ディレクトリにして実行します。

```bash
python -m pip install -r requirements.txt
python main.py
python -m pytest -q
```

## Copilotと進める手順

### 1. 不具合を再現する

最初にプログラムとテストを実行し、期待した金額と実際の結果を記録します。

### 2. 複数ファイルを調べてもらう

`main.py`、`cart.py`、`cart_item.py`、`product.py`、テストを添付します。

```text
READMEの仕様と実行結果を比較してください。
合計金額が正しくない原因を、関数の呼び出し順に調べてください。
どのファイルの処理が原因なのか説明し、まだ変更しないでください。
```

### 3. 計算を修正する

原因の説明をコードで確認した後、必要な箇所だけ修正するよう依頼します。初期テストを再実行し、3件すべての成功を確認します。

### 4. 数量の確認とテストを追加する

```text
READMEの数量の条件をCart.add_itemに実装してください。
不正な値ではValueErrorにし、既存のカートを変更しないでください。
既存のテストの期待値は変更せず、境界値と同じ商品の複数回追加のテストを追加してください。
関数名と引数は維持し、テストを実行して結果を報告してください。
```

追加テストでは、空のカートだけでなく、商品が既に入ったカートへの不正な追加も確認します。例外の種類・メッセージ、追加前後の明細、合計を比較してください。

## 変更範囲と提出

変更対象は主に `cart_item.py`、`cart.py`、`tests/test_cart.py` です。`products.json`、既存テストの期待値、商品価格を変更して成功させないでください。修正したコードとテスト、失敗の原因と検証結果を記した `work_notes.md` を提出します。
