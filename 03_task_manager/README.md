# 03 タスクの完了状態をJSONに保存する

タスクを追加し、JSONファイルへ保存するプロジェクトです。今回は、IDでタスクを完了させ、保存後に読み直しても完了状態が残るようにします。オブジェクトの変更とファイルへの保存が別の処理であることを確認します。

## 配布時の状態

- タスクの追加と、ID・タイトルの保存・読み込みは動きます。
- `Task.complete()` と `TaskManager.complete_task()` は未実装です。
- `completed` 属性はありますが、保存・読み込みではまだ扱っていません。
- 初期テストは **4件成功** します。これは追加と未完了タスクの保存を確認するテストであり、今回の完成条件を満たしたことにはなりません。

## ファイルと読む順序

| 順序 | ファイル | 役割 |
| --- | --- | --- |
| 1 | `main.py` | 読み込み、追加、保存、再読み込み、表示 |
| 2 | `task.py` | 一つのタスクの状態 |
| 3 | `task_manager.py` | タスク一覧の管理とIDによる操作 |
| 4 | `task_storage.py` | JSONとTaskオブジェクトの変換 |
| 5 | `tasks.json` | 2件の元データ。変更せずに使う |
| 6 | `tests/` | 管理処理と保存処理のテスト |

## クラス・関数と完成条件

| 対象 | 属性・メソッド | 動作 |
| --- | --- | --- |
| `Task` | `task_id: int`、`title: str`、`completed: bool` | タスクのID、内容、完了状態 |
| `Task.complete() -> None` | 未実装 | 自分自身の `completed` を `True` にする |
| `TaskManager` | `tasks: list[Task]` | 管理するタスク一覧 |
| `add_task(title) -> Task` | 実装済み | 最大IDの次の番号で未完了タスクを追加して返す。空ならIDは1 |
| `complete_task(task_id) -> None` | 未実装 | 指定IDのTaskの `complete()` を呼ぶ |
| `save_tasks(filename, tasks) -> None` | 要変更 | 各タスクの `id`、`title`、`completed` を保存する |
| `load_tasks(filename) -> list[Task]` | 要変更 | 保存された情報から、新しいTaskオブジェクトを作って返す |

- 存在しないIDを完了させようとした場合は、`ValueError("タスクが見つかりません")` を発生させます。
- 対象外のタスクの状態、ID、タイトル、並び順を変更しません。
- 完了済みのタスクを再度完了させても、エラーにせず完了状態を維持します。
- 保存時には完了状態をJSONの真偽値として書き込みます。文字列の `"True"` や `"False"` にはしません。
- 空のタスク一覧は `[]` として保存し、読み戻せます。
- 入力JSONは正しい形式で、IDは重複しない整数とします。ファイル破損への対応や入力メニューは追加しません。

## デモの完成形

`main.py` で、用意されたデータを読み、「テストを書く」を追加し、**IDが2のタスクを完了**させます。その後 `tasks_result.json` に保存し、そのファイルを読み直して表示してください。

```text
再読み込みしたタスク:
1: コードを読む [未完了]
2: 仕様を確認する [完了]
3: テストを書く [未完了]
```

配布時は2番も `[未完了]` と表示されます。表示の文字だけを変更せず、オブジェクトの状態と保存したJSON、読み直した状態を確認してください。

`tasks.json` は元データです。`main.py` を実行するたびに元データから開始し、結果用の `tasks_result.json` を上書きします。結果ファイルは提出不要です。

## 準備と実行

このフォルダーを作業ディレクトリにして実行します。

```bash
python -m pip install -r requirements.txt
python main.py
python -m pytest -q
```

テストにある `tmp_path` は、pytestが用意する一時フォルダーです。保存のテストで元の `tasks.json` を書き換えないために使っています。

## 確認するケース

完了、対象外のタスク、不明なID、2回目の完了をテストします。保存については、完了・未完了が混在する一覧を保存し、読み直した別のオブジェクトでもID・タイトル・完了状態・順序が一致するか確認します。空の一覧の保存と読み込みも確認してください。既存テストを維持し、これらを確認するテストを追加します。

## 変更範囲と提出

変更対象は `task.py`、`task_manager.py`、`task_storage.py`、`main.py` とテストです。状態変更を表示メッセージだけで代用しないでください。実装とテスト、変更内容と検証結果を記した `work_notes.md` を提出します。
