# 実習1 荷物の検索

追跡番号の一部や受取人から荷物を探せるようにします。検索処理、表示用の文字列、デモ、テストを追加します。

## 完成条件

- `DeliveryService.search_parcels(keyword: str) -> list[Parcel]`を実装します。
- 前後の空白を除き、英字の大小文字を無視し、追跡番号または受取人の部分一致で検索します。
- 空文字列、空白だけ、一致なし、空の一覧は`[]`を返します。
- どちらの項目にも一致する荷物も結果には1回だけ含めます。
- 元の順序とParcelオブジェクトを維持し、配送状態を変更しません。配達完了の荷物も検索対象です。
- keywordは文字列とします。元データの表記は変更しません。
- `build_search_report(service, keyword) -> str`は検索メソッドを呼び、先頭行を`検索結果:`、各行を`P002: Alice [受付済み]`の形式にします。
- 一致なしは`検索結果:\n該当する荷物はありません`を返し、末尾の改行は付けません。関数内でprintしません。
- main.pyの発送・配達デモを維持し、最後に空行と`alice`の検索結果を表示します。

```text
検索結果:
P002: Alice [受付済み]
P003: ALICE Suzuki [受付済み]
```

変更対象はdelivery_service.py、report.py、main.py、tests/です。Parcel、初期データと既存テストを維持します。履歴と配達員はまだ追加しません。

## 確認するケース

検索語 ` ALICE `、`p00`、`田`、空白、一致なし、空の一覧、完了済みの荷物を確認します。両方の項目に一致した荷物が重複しないこと、オブジェクトの同一性、順序、状態の保存と表示の完全一致もテストします。

```bash
python -m pytest -q
python main.py
```
