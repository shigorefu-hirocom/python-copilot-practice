# 実習4 配達状況を集計する

実習3を完成させてから開始します。配達員ごとに残っている荷物数と、未割り当ての荷物数を確認します。

## 完成条件

- report.pyに`build_delivery_summary(service: DeliveryService) -> str`を追加します。
- 未完了はstatusが`配達完了`以外の荷物です。
- 先頭行は`配送サマリー:`。登録された配達員を登録順に全員表示し、未完了の担当荷物数を数えます。0件でも表示します。
- 最後に、courier_idがNoneかつ未完了の荷物数を表示します。
- 担当荷物の取得には`get_courier_parcels()`を使います。集計で配送状態、担当、履歴、一覧の順序を変更しません。
- mainに空行と集計結果を追加します。それ以前の表示は維持します。
- 末尾の改行は付けません。GUI、ファイル保存、新しい依存関係は追加しません。

実習3のmainでは、P001は配達完了、P002とP003はC01担当、P004とP005は未割り当てです。

```text
配送サマリー:
C01: 田中 — 未完了 2件
C02: 佐藤 — 未完了 0件
未割り当て — 未完了 2件
```

配達員と荷物がともに空の場合:

```text
配送サマリー:
未割り当て — 未完了 0件
```

## 確認と依頼

完了・未完了の混在、担当0件の配達員、未割り当ての完了済み荷物を除くこと、空のデータ、集計前後に状態が変わらないことをテストします。

```text
実習4の集計仕様を読んで、どの荷物を数えるか先に説明してください。
get_courier_parcelsを使い、既存のデータを変更しない計画にしてください。
今はファイルを変更しないでください。
```

実装後は全テストとmain.pyを実行し、期待される件数と比較してください。
