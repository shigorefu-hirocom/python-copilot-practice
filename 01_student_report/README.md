# 01 学生の成績レポート

クラスの学生と点数から、成績レポートを作成します。学生とクラスのデータは用意されています。未実装のレポート関数を完成させ、学生ごとの平均点と合否を表示します。

## 配布時の状態

`main.py` は実行できますが、`build_report()` が未実装なので、次の案内が表示されます。

```text
レポートは未実装です。READMEを確認してください。
```

この状態は配布時の仕様です。`main.py` の文字列を完成例に書き換えるのではなく、渡されたオブジェクトからレポートを作ります。

## ファイルと読む順序

| 順序 | ファイル | 役割 |
| --- | --- | --- |
| 1 | `main.py` | データ作成とレポート表示の入口 |
| 2 | `student.py` | 一人の学生と平均点の計算 |
| 3 | `classroom.py` | 複数のStudentを保持するクラス |
| 4 | `data.py` | 練習用の学生とクラスの作成 |
| 5 | `report.py` | 今回完成させるレポート関数 |

## オブジェクトと関数

| 対象 | 属性・メソッド | 意味 |
| --- | --- | --- |
| `Student` | `name: str`、`scores: list[int]` | 学生名と点数 |
| `Student.average() -> float` | 実装済み | 平均点を返す。点数が空なら `0.0` |
| `Classroom` | `name: str`、`students: list[Student]` | クラス名と学生の一覧 |
| `Classroom.add_student(student) -> None` | 実装済み | 学生を追加する |
| `build_report(classroom: Classroom) -> str` | 未実装 | クラスの情報から表示用文字列を返す |

## 完成させる条件

- `report.py` の `build_report()` を実装します。関数名、引数、戻り値の型を維持してください。
- 戻り値は、改行で区切った一つの文字列です。関数の中では `print()` しません。
- 最初にクラス名、その次に `学生数: 人数` を表示します。
- 学生は `classroom.students` の順に表示します。
- 点数がある学生は `名前: 平均X.X点 / 判定` と表示します。平均点は `Student.average()` を使い、小数第1位まで表示します。
- 平均点が60点以上なら `合格`、60点未満なら `不合格` です。判定には丸める前の平均点を使います。
- 点数がない学生は、平均点や判定の代わりに `名前: 未受験` と表示します。
- 学生が0人の場合も、クラス名と `学生数: 0` の2行を返します。
- 学生名や点数、学生のリストを変更しません。末尾の改行は付けません。

用意したデータを使った完成後の出力は次のとおりです。

```text
Pythonクラス
学生数: 3
田中: 平均80.0点 / 合格
佐藤: 平均55.0点 / 不合格
鈴木: 未受験
```

## 実行と確認

このフォルダーを作業ディレクトリにして実行します。追加ライブラリは不要です。

```bash
python main.py
```

完成例に加え、空のクラス、点数がない学生、平均点がちょうど60点の学生を確認してください。確認用データは別のファイルで作成し、配布した `data.py` のデータは維持します。

## 変更範囲と提出

主な変更対象は `report.py` です。クラスや関数の公開名を変えず、結果を固定した文字列で返さないでください。変更したコードと、実装内容と検証結果を記した `work_notes.md` を提出します。
